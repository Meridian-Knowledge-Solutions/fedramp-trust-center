# Certification Package API

Programmatic access to the Meridian Knowledge Solutions FedRAMP 20x Certification Package (FedRAMP ID **FR2527956755**). Everything is static JSON served over HTTPS from this Trust Center — no authentication, `GET` only, no new infrastructure. This is the documented programmatic access CR26 asks of trust centers (CDS-TRC-PAC, CDS-TRC-HMR) and the groundwork for the Class D machine-readable package requirement (CDS-CSX-API, RFC-0036).

**Base URL:** `https://meridian-knowledge-solutions.github.io/fedramp-trust-center`

## Start here

| Endpoint | What it is |
|---|---|
| `/api/v1/manifest.json` | The package index: every machine-readable artifact with its stable path, media type, size, SHA-256, last-modified commit date, the producer's own `generated_at`, cadence, the CR26 rules it serves, and links to its JSON Schema and human-readable counterpart. |
| `/api/v1/manifest.schema.json` | JSON Schema (2020-12) for the manifest. |
| `/api/v1/manifest-history.jsonl` | Append-only log of every publish: `generated_at`, `package_version`, `sequence`, SHA-256 of the manifest, which artifacts changed. One JSON object per line. |
| `/api/v1/ksi-runs-index.json` | Every per-run KSI status snapshot (4-hour granularity since 2025-05-29) with its immutable URL. |
| `/api/v1/policies.json` | Machine-readable reference for each published policy/procedure: name, file, summary, word count, version (when stated), last update, SHA-256 (CDS-CSO-IRP). |

```bash
curl -s https://meridian-knowledge-solutions.github.io/fedramp-trust-center/api/v1/manifest.json \
  | jq '.artifacts[] | select(.category=="ksi") | {id, url, generated_at, sha256}'
```

## Contract

- **Stable paths.** Artifact paths are the contract. They are listed in `manifest.json` under `artifacts[].url` (and `stable_paths` for the API files themselves). A path rename or a removed field bumps `manifest_version`; everything else is additive.
- **Versioning.** Artifacts are replaced in place on each publish and identified by `sha256` + `generated_at`. `package_version` is `YYYY.MM.DD.<sequence>`; `sequence` increases by one per publish and matches the line count of `manifest-history.jsonl`. Per-run KSI history files are immutable once written and are retained indefinitely (see the retention policy linked from the index).
- **Integrity.** Verify any download against `sha256` in the manifest. The manifest's own hash is recorded in `manifest-history.jsonl`.
- **Human + machine.** Where a human-readable rendering exists (HTML, Markdown, PDF, XLSX) the artifact entry links it under `human_readable`; both are produced by the same automation from the same data (CDS-CSO-CBF).
- **Completeness.** Files served under `/data`, `/trust-center` and `/reports` that the catalog does not describe appear under `uncatalogued`; legacy duplicate paths appear under `deprecated` with their canonical replacement. Nothing served is undocumented.
- **Cadence.** The validation pipeline republishes every 4 hours; VDR metrics daily; reports on their own schedule (see each artifact's `cadence`). The Trust Center redeploys within 15 minutes of a data publish.

## Categories

`cso` public offering record · `ksi` validation output and register · `ksi-history` metrics over time · `vdr` vulnerability detection and response · `scn` significant change notifications · `reports` ongoing / quarterly certification reports · `mas` boundary and dashboard · `scg` secure configuration guidance · `assessments` independent assessments and FedRAMP documents · `policies` · `remediation` · `crm` customer responsibility matrix · `schemas` · `integrity` pipeline self-checks · `meta`.

## Provenance

The manifest is generated by `scripts/generate_package_manifest.py` in the [validation pipeline repository](https://github.com/Meridian-Knowledge-Solutions/fedramp-20x-submission-final) from `config/package_manifest_catalog.json`, on every public data sync. The same artifacts are also attached to GitHub releases listed under `additional_distribution`.
